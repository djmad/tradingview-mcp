## Decisions and limits

- `selected-now`: #528, #543, #539, #538, #534, #548 selected for current integration; implementation and final regression evidence remain in the main merge report.
- `selected-adaptation`: #555/#522 Pine safety family implemented and tested by a dedicated integration agent, while preserving this fork's dispatcher and permission structure.
- `integrated-tested`: #549 latest-bar study values, #537 date history paging, #519 child Electron environment cleanup; 15 focused tests passed together, plus a child-environment mock. #491 locale selector was integrated after static patch review, not a live locale test.
- Integration follow-through: #345/#158 concerns were addressed with visible bound Monaco selection and saved-script guards; #197 received strict chart-URL selection and API readiness checks with regression tests. #411 and #449 contain broader connection/timeout designs that need careful target-safe adaptation.
- `already-covered` means the relevant change is present in upstream baseline or the local fork, as described in the rationale; it does not mean GitHub merged the PR.
- `defer-feature` and other deferred entries are proposals for later user decisions. No optional feature was authorized or implemented by this review.
- Personal reports/layout preferences, sandbox-disabling launch flags, trading/account expansions, and older dependency pins are not adopted wholesale.
